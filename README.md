## ✨ 插件简介

一款为Minecraft服务器设计的在线时间奖励插件，提供连续在线递增奖励系统。插件采用可爱的二次元风格，让玩家在获得奖励的同时感受到乐趣。

## 🎯 主要特性

### 🎮 **智能奖励系统**
- **基础奖励**：普通玩家200硬币/小时，赞助玩家800硬币/小时
- **连续加成**：每连续在线1小时增加100硬币奖励
- **奖励上限**：每小时最高1800硬币
- **自动递增**：200→300→400...（普通），800→900→1000...（赞助，拥有CFC.zanzhu权限）

### ⏰ **时间管理机制**
- **断开重置**：玩家退出游戏，连续在线计数立即归零
- **每日重置**：每天00:00自动重置所有玩家连续计数
- **预重置保护**：23:58提前发放未满1小时的按比例奖励
- **防刷系统**：精确的时间计算和多重验证

### 🎨 **可爱二次元风格**
- **34种随机消息**：每次奖励都有不同的可爱提示
- **丰富颜文字**：使用各种二次元风格的颜文字和符号
- **彩色界面**：多彩的消息显示，视觉效果好
- **特殊通知**：达到最高奖励时有特殊提示
